# Handy Notdienst Site Standards

Use this checklist for future site changes.

- Keep WhatsApp green as the main action color; use warm amber only for trust/warranty cues.
- Use light product zones for phone photos so devices stay easy to inspect.
- Prefer responsive images: WebP first, PNG fallback, `srcset`, accurate `sizes`, and lazy loading outside the first viewport.
- Preload only the first-viewport hero/product image, not the full image set.
- Keep useful metadata current: canonical URL, Open Graph image, Schema.org, sitemap, and robots sitemap entry.
- Track important actions through `HN_trackEvent`: WhatsApp clicks, model selection, repair selection, and FAQ toggles.
- Respect `prefers-reduced-motion` for all animation and interaction polish.
